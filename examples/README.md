# 核心规则示例

`core.py` 是为作品集重写的纯函数/内存示例，没有网络、模型、数据库或媒体依赖。目的在于展示产品约束如何变成可执行规则，不是开源生产调度器。

| 模块 | 解释的设计 | 简化边界 |
|---|---|---|
| `plan_cues` | 默认连续、真正重置、5秒与密度约束、用户覆盖 | 输入已结构化，不做视频理解；边界优先级只是示例启发式 |
| `resolve_identity` | 整集→阶段→Cue、有理由的覆盖 | 不包含生产完整证据绑定 |
| `compile_music` | Hook不硬塞给生成起点、纯器乐、功能路由 | 提示词为示例，不代表已发出的供应商请求 |
| `group_sources` | 相同配方去重，Cue与付费次数分离 | 不推断不同配方是否音乐上相容 |
| `reserve_once` | 重复提交幂等、预算不足不写入 | 仅内存，无事务/并发保证，生产需要数据库唯一约束 |
| `rank_excerpts` | 用代理特征推荐窗口而非宣判审美 | 预计算合成特征，无音频分析，无小节检测 |

运行：`python3 -m unittest discover -s tests -v`。输入例子为 [scenario.json](scenario.json)，所有人物和事件均为虚构。
