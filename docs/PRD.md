# PRD｜整集剧情配乐工作台

版本：作品集公开版 1.0 · 2026-09-21。依据当前 Alpha 重写，不直接发布过时的初版 PRD。描述产品目标与现状；交互 Demo 不等于这些能力的在线实现。

## 1. 用户、任务与价值假设

目标用户是独立 AI 漫剧、剧情短视频创作者与小团队。核心输入为30–180秒、已定剪、保留对白和叙事音效的待配乐视频。既有选择包括曲库、剪辑软件自动配乐和文生音乐。不是所有人都需要替换现有工具。

JTBD：当画面已完成，我希望少做反复找歌与拼接，就获得风格合适、叙事连贯、对白清楚的整集配乐；只调整不满意的位置。

价值假设：减少人工操作和返工，且创作者愿意实际采用，而非只说概念有趣。

## 2. 目标、非目标、成功口径

北极星候选：**完成试听的有效整集样本中，经0–1次修改被创作者确认可发布的比例**。另行记录实际发布与二次提交，不能用导出代替采用。失败和退出样本必须进入漏斗，避免只在成功者中报告高质量比例。

非目标：训练自有音乐模型、公开 UGC 社区、DAW 多轨编辑、可靠的人声分离、任意风格都一次成功、精确可变 tempo map 作曲、自动审美裁决。

## 3. 主要用户路径

1. 创建项目并上传定剪视频，默认保留原音，不做对白分离。
2. 选择「一键生成整集配乐」或「先看看剧情安排」。第二条路径的分析仍可能产生费用，不是免费试听。
3. 系统完成转写、画面采样、剧情观察与字段规划。
4. 自动模式直接执行；安排模式显示普通语言节点，用户选择保持连续/换音乐，不要求知道 Cue 或 BPM。
5. 按源曲分组预留费用，生成、粗选和装配。
6. 同屏试听与局部调整，保存当前版本，导出整集。更新编排后需重新合成，不能下载过期版本冒充新结果。

## 5. 关键业务规则

### 音乐变化

仅持续的人物关系/权力格局或完整场景/叙事情境重置支持自动换曲。最低单段5秒；数量严格小于总秒数/10，且不超过12段。例如45秒最多4段，40秒最多3段。**满足上限不意味着应该生成这么多段。** 用户明确位置优先于自动建议，但不能绕过时长和费用约束。

### 分层字段

产品政策 → 整集音乐身份 → 阶段覆盖 → 单段功能与例外。观测、推断、产品规定和用户决定分别留存。允许“古风宫廷 + 现代电子”，不把题材标签硬映射到五声音阶或某一种乐器。

### 音乐生成与选段

Mureka 当前主要使用内部剧情/字段编译后的文本，不上传视频。生成完整源曲后再选成熟窗口，不能保证生成第0秒有 Hook。Stable 氛围生成留出剪辑余量，当前参考为用途长度加10秒并受接口/产品时长限制。长源曲和短 Cue 解耦。

### 人声与原音

有对白或对白状态未知时，新增配乐默认纯器乐，禁歌词与无词哼唱。产品设计中的“连续超过15秒无对白才可能开放演唱”不是当前自动演唱功能，也不是ASR空白即可证明安全。提示词禁用人声不保证音频绝无哼唱，仍需要听评。

### 成本与恢复

预算预留不是实际账单；唯一源曲数不是 Cue 数。相同生成配方可去重，但不能为了省钱强行合并不同情绪需求。供应商提交未知时保留状态并查询/人工处置，不自动重复付费请求。错误必须保留已完成分析，不要求用户为所有系统错误删除重传。

## 6. 非功能与数据边界

| 维度 | 要求 / 边界 |
|---|---|
| 可用性 | 刷新后可见持久化进度；不得把全部错误写成“需要核对” |
| 隐私 | 媒体私有访问、到期提示；不公开未发布作品或带签名链接 |
| 稳定性 | 任务幂等、来源摘要绑定、结果与版本一致，恢复不覆盖模型原稿 |
| 体验 | 减少不必要的中间审批；复杂设置渐进展开；窄屏上下布局 |
| 可观测性 | 有阶段/错误码/成本预留，日志不泄露密钥或完整用户内容 |
| 质量 | 技术成功与审美可用分开；没有声称完全自动理解音乐叙事 |

## 7. 已交付与缺口

封闭 Alpha 已跑通主要生成、选择、编排与导出链路，并经历真实自测迭代。当前薄弱项包括模型随机性、自动粗选的语义边界、部分供应商失败原因区分、跨题材质量和规模化采用证据。公开版不把这些缺口隐藏为“智能算法”。
