# 用户研究｜从访谈意向到真实采用

这是经去标识化和概括后的研究方法复盘，不包含原始访谈、姓名、账号、粉丝量、作品名、未发布台词或联系方式。原始材料的处理许可不等于公开传播许可。

## 研究问题

1. 创作者最近一集怎样找音乐、试多少条、在哪些地方放弃？
2. 不满意的是风格、叙事结构、对白冲突还是剪辑成本？
3. 新工具产生什么可观察变化，才值得迁移？
4. 谁决定采用？“觉得不错”、下载、发布、付费是否为不同人/阶段？

## 招募与方法调整

早期招募过度避免介绍产品，受邀者反而不明白为什么要参与。调整为明确解释正在研究“完整剧情视频的配乐工作流”，提供可试玩原型，但不先问“你是否需要智能卡点”。先回溯最近一次行为，再展示方案，前后分开记录。

部分受访者认为现有剪辑软件已经足够。这不是“用户不懂 AI”，而是替代成本与痛点强度的真实信号。试用招募优先找愿意提交完整作品、保留既有方案、愿意对比的创作者，而不是只收集赞同。

## 已观察到的模式与限制

| 观察 | 支持的判断 | 不能推导 |
|---|---|---|
| 有创作者对音乐风格匹配不满意，不会做复杂后期 | 存在工作流缺口，自动交付可能有价值 | 全部创作者都需要新工具 |
| 局部片段好评，但无法承接后续内容，未采用 | 需要整集上下文与连续交付 | 好评等于留存或付费意愿 |
| 另一类快节奏作品拒绝成品风格 | 单题材正样本不能代表迁移成功 | 该题材永远不适合 AI 配乐 |
| 项目负责人自测推动多轮规则调整 | 产品已进入使用反馈驱动迭代 | 等同于独立用户实验或规模化验证 |

研究样本少，存在招募偏差；部分回答发生在卖点介绍之后，不能写成用户自发提出的需求。公开仓库不虚构代表性访谈规模。

## 下一轮半结构化访谈

### 展示产品前（15 分钟）

- 回忆最近一次完成配乐的作品：从哪里开始？按时间顺序带我走一遍。
- 最近一次换掉某段音乐是什么时候？为什么？最终如何决定？
- 能否比较最初版本与最终版本？其中哪些改动耗时最多？
- 如果不修改会有什么影响？谁注意到了问题？

### 原型任务（15–25 分钟）

给同一完整作品提供既有方案与生成方案，记录第一次独立操作、卡住位置、修改次数及选择理由。随机化展示顺序；不要提醒某处应该特别精彩。允许“两个都不用”。研究者干预单独计时。

### 任务后（10 分钟）

- 你会保留、替换还是都不用？请给出具体位置。
- 若只能改一次，改哪里？为什么不是其他位置？
- 完成后是否愿意用于当前作品？何时能确认实际发布？
- 第二个真实任务什么时候发生？不要仅询问抽象的使用意愿。

## 记录模板

```text
匿名研究编号 / 日期 / 任务类型 / 同意范围
既有工作流与耗时（自报还是观察）
原型操作耗时 / 系统等待 / 研究者协助分钟
候选选择：生成方案 / 原方案 / 均不用
拒绝原因与时间点 / 修改次数
可发布判断 / 实际发布证据 / 后续任务提交（分别记录）
未回答的问题 / 主持人诱导风险 / 可推导与不可推导结论
```

量化问卷在稳定概念与关键问题后再使用，不用筛选问卷替代实际任务观察。
