# 指标与埋点计划

以下是测量设计，不是已经取得的经营数据。生产链路存在任务、版本和费用记录，但本页完整产品漏斗与留存仪表盘尚未作为已验证能力交付。

## 指标树

| 目标 | 指标与分母 | 风险 / 配套观察 |
|---|---|---|
| 创作价值 | 经0–1次修改确认可发布的整集 / 完成评价的有效整集 | 同时报未评价、放弃和技术失败，避免幸存偏差 |
| 实际采用 | 用户确认真实发布的整集 / 有效提交 | 导出不等于发布，不能自行抓公开账号代确认 |
| 效率 | 上传到导出的总时长、主动操作分钟数 | 模型等待与人工操作分开；研究者协助单独计时 |
| 稳定性 | 技术完成的整集 / 发起生成的有效整集 | 每阶段失败率、未知提交、重复调用 |
| 成本 | 实际供应商成本 / 完成整集；成本 / 采用整集 | 预留不同于消费；失败仍有费用，不能只算成功调用 |
| 复用 | 14日内提交第二集的创作者 / 已到观察窗口的首集创作者 | 样本成熟度和邀请偏差；未满14日不记未留存 |

## 事件建议

| 事件 | 最小属性 | 用途 |
|---|---|---|
| project_created | 匿名用户/项目ID、入口版本 | 新建转化 |
| upload_validated | 时长桶、校验结果 | 素材阻力 |
| flow_started | automatic/choose、规则版本 | 模式选择 |
| analysis_ready | 阶段耗时、安全错误码 | 分析可靠性 |
| arrangement_confirmed | 建议段数、最终段数、改动类型 | 用户是否修正模型 |
| generation_reserved | 唯一源曲数、预留金额、币种 | 成本解释 |
| generation_finished | provider类别、耗时、结果状态 | 供应商可用性 |
| excerpt_changed | 推荐位次、改动范围 | 粗选收益 |
| render_finished | 编排版本、耗时、成功与否 | 装配可靠性 |
| export_requested | 成片版本 | 只衡量下载意图 |
| outcome_reported | 可发布、修改次数、是否实际采用、原因标签 | 质量与采用 |

不记录原始台词、帧图、邮箱、完整提示词或带签名URL到普通分析平台；诊断资料单独权限、保留期限与脱敏。

## 假设检验优先级

第一轮用5–8名创作者的任务观察作为招募目标（**尚未完成的计划，不是已有样本数**），不做显著性承诺。先检查真实采用、主要拒绝原因及操作负担；稳定后再决定是否值得做量化A/B。

如果导出上升但采用不变，应检查音乐质量或导出动机，而不是只庆祝按钮转化；如果成功率上升但人工协助增加，也不能称为自动化效率提升。
