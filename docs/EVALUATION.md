# 模型评测与选型｜能力边界比排行榜重要

本页是项目实测的历史决策摘要，截至2026-09-21；不是当前全市场排名。API可用性、定价、授权须在采购时重新核实。本仓库不附第三方媒体，也不要求评审者付费复现实验。

## 评价单位

完整一集是产品单位；模型输入、生成源曲、外部选段和混音结果分别记录。只看生成原曲会漏掉装配成本，只看最终成片又会把人工编辑贡献误算为模型能力。

评价维度：风格与叙事匹配、音乐发展、对白竞争、入口成熟度、必要重置、结尾自然度、0–1次修改可用性、人工分钟、独立调用数与实际费用。

## 历史路由结论

| 候选 | 本项目观察与选择 | 限制 |
|---|---|---|
| Mureka V9 CN | 节奏/动机与部分叙事重置的主后端；当前文字输入 | intro 与长曲结构、solo偏置、结尾继续发展，需选段和装配 |
| Stable Audio 3.0 | 纹理与氛围型主后端，留剪辑余量 | 强入口不总成立；文化身份和人声遵循仍需听评 |
| Eleven Music v2 | 有过成立的结构结尾，作为实验备选 | 跨样本一致性不足；勿与正在用于转写的 Eleven Scribe 混同 |
| Suno Studio | 音乐性/交互质量标杆 | 历史实验时账户无获准平台接入，不能以非正式 API 替代采购条件 |
| ACE-Step | 开源路线观察项 | 已测环境/输入受限，不足以进行公平质量排序 |
| Lyria | 暂缓 | 未完成质量实测，不宣布优劣 |

题材 × 角色 × Adapter 都会影响结果。某类氛围正样本不意味着全模型对所有题材占优。

## 一个有明确分母的历史对照

两段30秒剧情素材，每个模型每段3候选；同批听评的“0–1次修改可用”记录为：

| 实验 | Mureka | Eleven Music |
|---|---:|---:|
| 信息揭示 / 悬疑对白 | 2/3 | 1/3 |
| 轻喜剧 / 隐性威胁 | 1/3 | 0/3 |
| 合计 | 3/6 | 1/6 |

样本很少、主要由项目负责人听评，模型原生输入方式不同；这支持当时任务内的路由选择，不支持总体能力显著性结论。后期追加不同提示试验不得偷偷加入原分母。历史资料保留在私有证据库，公开仅保留汇总结论。

## 实验模板与证据等级

1. 冻结用途、输入、模型版本、候选数、预算、拒绝项和允许的后处理。
2. 保存请求/输出版本；盲评前不暴露模型名，固定试听音量和片段边界。
3. 先评价绝对可用性，再排序；允许全部不可用。
4. 区分文件/API失败与音乐质量失败；没有音频不能打审美零分。
5. 解盲后记录原因，下一轮再修改合同，不在当轮无限改提示“追好结果”。

证据分开写：重复同任务观察、单样本能力存在、官方接口事实、不公平链路/推断。基于单样本的选择是探索决策，不是假装统计显著。

## 自动复评器与自动选段

技术检查可做时长、解码、静音、过载和边界检查。自动粗选使用能量、瞬态与稳定性等代理特征，不等于判断“音乐是否理解画面”。历史复评曾排除人耳可用结果，因此审美判断仍交给创作者。

本仓库不训练或展示新的音频语义模型。公开 `rank_excerpts` 是预计算特征的教学排序，不能拿它识别真实小节强拍。

## 下一轮实验的退出条件

用未参与提示调整的跨题材完整视频；比较既有曲库工作流与产品结果，记录采用和时间。不因某个样本好听就加新底模；若目标角色持续无增益，暂停扩张，先修输入/规划/装配中证据最强的一环。
