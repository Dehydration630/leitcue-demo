# 交付状态与下一阶段

## 已交付（私有 Alpha；公开版为模拟）

- 一键整集流程，以及共用分析结果的可选剧情安排。
- 分层字段、叙事重置分段、最短时长与数量约束。
- 文本音乐路由、相同配方保守去重、预算预留、异步状态。
- 粗选推荐、原对白/音效保留、确定性装配、局部调整与导出。
- 界面简化、版本留存、发布备份和真实自测反馈闭环。

## 仍有边界

- 自动选段不理解完整乐句/和声，也不保证强拍精确。
- 模型提示可能仍产生人声、旋律过密或情绪失配。
- 相同配方去重不等于跨情绪、跨集智能素材复用。
- 多题材入口不是全题材质量保证。
- 外部供应商账户/额度/网络影响可用性，错误分类还需持续完善。
- 用户采用、付费和留存未被充分验证。

## 下一阶段优先级

| 阶段 | 做什么 | 进入/退出条件 |
|---|---|---|
| P0 稳定性 | 供应商错误分类、恢复说明、减少误暂停 | 失败可定位，不重复付费、不丢已完成分析 |
| P0 价值验证 | 完整作品与既有方案对照 | 创作者真实选择、实际采用、二次提交证据 |
| P1 音乐质量 | 首尾精修、乐句/人声检查、粗选收益 | 留出样本上优于现有粗选，不仅拟合单秒数 |
| P1 成本 | 预算感知的源曲规划 | 降低每采用整集成本，不牺牲必要重置 |
| P2 系列化 | 跨集音乐身份、角色主题和复用 | 用户有持续剧集需求且单集价值成立 |

暂不优先：训练大模型、DAW插件、公开社区、复杂多Agent编队或固定tempo map作曲。它们可能有价值，但不应阻塞当前完整任务闭环。
