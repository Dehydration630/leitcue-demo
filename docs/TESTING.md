# 测试用例与验收

测试不是证明“AI 永远正确”，而是让输入合同、失败边界和听评标准可复现。

## 需求追踪矩阵

| 场景 | 操作 / 输入 | 预期 | 验证方式 |
|---|---|---|---|
| 连续叙事 | 同场景情绪改变、镜头切换 | 保持同一段音乐 | Python 规划单测 |
| 叙事重置 | 45 秒视频，39 秒关系重置，证据已绑定 | 形成 39 + 6 秒两段 | Python + JS 单测 |
| 不确定推断 | 重置没有证据或并非持续状态 | 不自动新增边界 | Python 单测 |
| 密度限制 | 45 / 60 秒剧集 | 最多 4 / 5 段，不自动用满 | Python + JS 单测 |
| 短段限制 | 手选边界距离前后不足 5 秒 | 提示调整位置，不开始生成 | Python + JS + 浏览器 |
| 用户优先 | 主动选全片不换音乐 | 一段覆盖整集，保留分析 | Python + 浏览器 |
| 层级继承 | 整集“宫廷”，局部只改能量 | 场景身份不丢失 | Python 单测 |
| 局部覆盖 | 更换已知身份字段但没有理由 | 拒绝不透明覆盖 | Python 单测 |
| 开场人物 | 首段有人物或人物信息不明 | 成熟节奏为选段要求，不承诺模型零秒 Hook | Python 单测 |
| 无人物铺垫 | 首段明确无人物、氛围主导 | 允许氛围路由 | Python 单测 |
| 对白保护 | 编译音乐描述 | 显式纯器乐、无人声/哼唱 | Python 单测；真结果仍需听评 |
| 源曲复用 | 合同完全一致，非重置、无未知 | 同一源曲组；不凭题材相同合并 | Python 单测 |
| 付费幂等 | 相同操作重复预留 | 只留一份；参数冲突则报错 | Python 单测 |
| 状态未知 | 提交状态 unknown | 禁止当成新任务再次付费提交 | Python 单测 |
| 预算不足 | 整数计量超过额度 | 拒绝且账本不变，原因明确 | Python 单测 |
| 自动粗选 | 合成代理特征 + 片长 | 过滤越界/低覆盖，稳定排序最多 3 个 | Python 单测 |
| 页面交互 | 剧情选择 → 模拟生成 → 局部调整 → 导出 | 状态一致，导出为标明 synthetic 的 JSON | 浏览器人工验收 |
| 移动端 | 390px 宽，核心操作和表单 | 不横向溢出，侧栏上下排列 | 浏览器人工验收 |
| 公开安全 | 文件清单、链接、常见秘密模式 | 无媒体、真实运行配置、绝对路径或失效本地链接 | 发布扫描 + 人工审阅 |

## 可复现命令

在仓库根目录运行，Python 3.11+ / Node.js 18+，均不需要第三方依赖：

```bash
python3 -m unittest discover -s tests -v
node --test tests/demo.test.mjs
node --check assets/app.mjs
python3 scripts/check_publication.py
```

GitHub Actions 对公开示例执行上述检查。不把这些测试数量当成生产测试覆盖率，也不把静态演示通过当成真实模型效果通过。

## 真实整集验收卡（研究模板）

| 维度 | 记录方法 |
|---|---|
| 开场成立 | 是否快速建立所需张力？有无拖沓引子？ |
| 叙事连续 | 是否因镜头/情绪变化而无意义换音乐？ |
| 关键重置 | 新人物关系或新场景是否被清楚表现？ |
| 对白与音效 | 原对白可懂，叙事音效保留，无无意人声争抢 |
| 首尾与衔接 | 有无生硬硬切、错拍、过长空白或未完成新乐句？ |
| 修改成本 | 创作者需要几次修改，耗时多久，修改原因是什么？ |
| 实际采用 | 是否真的放入作品？没有采用时记录原因，不用评分替代 |

盲听时先冻结输入与验收标准、随机标签，再解盲模型身份。重复采样、失败结果、人工剪辑步骤都保留；未知不记成功。不要求所有事件都做 Hit，不为了测试“卡上了”而奖励无意义强音。

## 本展示代码不覆盖的生产风险

- 数据库事务、并发预算锁、任务租约和跨进程幂等。
- 供应商实际扣费、内容政策、账号权限、网络断连和未知任务对账。
- 实际音频节拍/结构识别、真实渲染、采样精度和整集听感。
- 隐私授权、媒体删除与恢复、安全隔离、用户鉴权。

这些是实际产品的独立验收面，不应由几十行示例替代。参见 [架构边界](ARCHITECTURE.md) 与 [下一阶段验证](ROADMAP.md)。
