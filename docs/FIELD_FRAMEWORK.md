# 字段框架｜从看见剧情到控制配乐

字段是可执行设计，不是给模型的一串形容词。下列是公开简化合同，真实系统有更细的类型、来源绑定、版本兼容与持久化；示例字段不保证与生产API逐项同名。

## 层级与职责

| 层级 | 示例字段 | 来源 | 影响 |
|---|---|---|---|
| 证据 | 时间窗、台词引用、采样帧 | 转写/画面 | 模型可以依据什么；不直接成为音乐参数 |
| 整集叙事 | 时代、场景、组合题材、不确定性 | 模型观察 | 为所有音乐段提供上下文 |
| 产品政策 | 人物开场Hook、默认纯器乐、5秒下限、密度上限 | 产品规则 | 高于低层创作提案，不伪装成模型事实 |
| 整集音乐身份 | 音色方向、宫廷/都市气质、避免项 | 规划提案/用户意图 | 每段继承，不要求重复填写 |
| 阶段/单段例外 | 覆盖字段、理由、来源 | 模型提案/用户 | 有限覆盖，保留差异的解释 |
| 音乐功能 | 节奏/氛围/动机、能量、旋律密度、入口/结尾 | 字段编译 | 路由、提示词、选段与装配分别消费 |
| 执行 | provider、source_group、duration、excerpt | 确定性程序 | 预算、任务、合法时间范围与输出版本 |

优先级不是所有字段简单覆盖：权限与费用不能被创作字段放宽；产品纯器乐政策不能被低层“想要哼唱”绕过。用户选择时间点是创作意图，不需要编造台词证据来证明。

## 哪些信息传到哪里

| 输入或决策 | 编译字段 | 下游消费者 | 不能保证什么 |
|---|---|---|---|
| 开场有人物/状态未知 | mature_rhythm入口要求 | 路由、文本方向、粗选器 | 不能保证模型第0秒开始Hook |
| 整集宫廷背景 | setting=palace | 每Cue提示上下文 | 不自动指定五声音阶/古筝 |
| 同场景情绪改变 | local event | 保留观察、段内方向 | 不是自动换曲依据，也非必然音效Hit |
| 持续关系重置 | reset + 前后证据 | 边界编译 | 验证结构不证明语义绝对正确 |
| 有对白 | instrumental | 文本与供应商纯器乐参数 | 实际音频仍可能出现哼唱 |
| atmosphere载体 | texture + duration余量 | Stable适配与选段 | 短时长不一定更便宜 |
| 用户取消边界 | creator_boundaries | 重编译、任务、装配 | 不修改模型原稿或重做分析 |

## 合成例子

原创45秒剧情：当代工作室内，两人争执后缓和；39秒一封新证据改变主导关系。9秒切镜不换音乐，39秒可换。输入/输出例子见 [examples/scenario.json](../examples/scenario.json)。

```json
{
  "episode": {"era": "contemporary", "setting": "studio", "palette": "electronic"},
  "event": {"at_ms": 39000, "kind": "relationship_reset", "persistent": true},
  "cue": {"carrier": "rhythm", "energy": "high", "voice": "instrumental"},
  "decision_source": "model_proposal"
}
```

## 不确定性与容错

保留原始模型文档，编译可执行副本。非法字段、空引用、跨边界标记不是同一种错误。非关键格式可规范；缺失重置证据时默认合并，不伪造关系变化；权限、费用和不合法执行窗口不能静默放宽。

视频理解边界包括稀疏采样漏掉表情、字幕与音频不同步、说话人归属、反讽、快速切镜、画外音和语义歧义。字幕有助于理解但不保证视觉事实；推荐清晰对白/字幕是输入建议，不应把模型错误都归咎于素材。
